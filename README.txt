TAK Duty Control - Offline Prototype

روش استفاده:
1) فایل index.html را باز کنید.
2) کاربر را انتخاب کنید و وارد شوید.
3) اطلاعات فعلاً داخل مرورگر همان دستگاه ذخیره می‌شود.
4) برای تست روی موبایل، کل پوشه را روی GitHub Pages یا یک هاست ساده بگذارید.
5) این نسخه آفلاین است و چند دستگاه با هم Sync نمی‌شوند.

بخش‌ها:
- داشبورد
- وظایف
- تعریف وظیفه
- گزارش روزانه
- پرسنل
- تجهیزات و PM
- گزارش عملکرد

نکته:
این نسخه پایه است. بعداً همین معماری را به Supabase/PostgreSQL وصل می‌کنیم.
